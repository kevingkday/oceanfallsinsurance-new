What I've built

Software for captive feasibility, and for the renewal file on a broker's desk.

CanadianCaptive

A captive feasibility pre-screen, with a domicile reference behind it.

  • Industry, premium, objective, and five-year loss ratio come back as a viability rating and a structure: single-parent, cell, or group.
  • Legislation, minimum capital, and tax notes for each domicile are generated from one dataset.

Stack · HTML, Cloudflare

Live site GitHub

TwinCover

A local assistant for a commercial renewal.

  • A local model reads the declarations and fills named insured, limits, dates, and premium. The broker confirms the fields next to the policy text.
  • It sorts the PDF: policy, binder, certificate, endorsement, or quote.
  • Coverage questions are answered from that client's documents, with the section cited. The client letter can be polished before it exports to Word or PDF.

Stack · Python, FastAPI, React, Ollama, ChromaDB

Live site GitHub

CaptiveStack

A workspace for group-captive feasibility.

  • A member survey builds the file: current policy, exposures, five-year claims, loss runs, retention, and a capital pledge.
  • Premium, loss history, and group size become a fit score, plus an illustrative five-year surplus range.
  • Association staff, members, and reviewers each open their own part of the file.

Stack · SvelteKit, Cloudflare Pages, D1

Live site GitHub
